# Degree-90 S-class frontier

## Decision problem

The surviving identity-cover arithmetic is controlled by a marked ideal
class `[A_R]` in the `S`-class group of a degree-90 field `F90`. The exact
decision is whether there exist an `S`-unit `u` and an element `beta` with

```text
(x(R) - theta) * u = beta^2.
```

## Certified reductions

- `F90` can be constructed as a relative cubic over a degree-30 base;
- its discriminant is `2^303 * 72559^18`;
- the two-primary `S`-class dimension splits into a degree-30 contribution
  and a relative norm-kernel contribution;
- the norm identity puts every relevant elliptic descent image in the
  relative kernel;
- a compressed representative uses three unramified degree-one primes.

## Bounded evidence, not a theorem

Bounded short-vector and elementary-unit searches produced no witness. This
is recorded search evidence only and is not part of the proved reductions.

## Open boundary

The class `[A_R]` is not proved trivial or nontrivial. A search miss cannot
be read as an impossibility proof, because a shortest element of a principal
ideal need not generate it. The live alternatives are an explicit global
square witness or a separating character of the two-primary `S`-class
group.
